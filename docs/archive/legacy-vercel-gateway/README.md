# Historical Vercel Gateway source

These files preserve the retired Vercel/FastAPI endpoint, its GitHub comment-trigger route, and its Neon-backed deployment examples. They are archival references only and are not imported by the active Sites runtime.

The archive is kept so earlier implementation and security decisions remain auditable. Do not use the archived entrypoint, workflows, or configuration for new deployments. The current private ChatGPT service uses Sites, Cloudflare D1, R2, and the local Runner.
