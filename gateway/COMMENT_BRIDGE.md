# Retired GitHub Comment Bridge

The GitHub comment-to-Gateway path has been retired. Its workflow is removed,
and `ci_policy.json` is disabled with a non-routable legacy origin. Do not enable
or deploy this bridge. It depended on the legacy Vercel/Neon Gateway path and is
not part of the supported ChatGPT Sites + D1 product.

The `ci_bridge.py` and related tests remain only as legacy behavioral reference
while equivalent Sites/D1 behavior is implemented and accepted. New experiments
must use the private Sites MCP tools; paid providers remain independently gated.
